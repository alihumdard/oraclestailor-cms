1 Initial Setup

  1. Clone and install dependencies:
    composer install npm install
  2. Configure environment:
    Copy .env.example to .env. It's already configured for SQLite database (perfect for small/medium tailoring business).
    cp .env.example .env
  3. Generate application key:
    php artisan key:generate

2 Database Setup

  1. Create SQLite database file:
    touch database/database.sqlite
  2. Run migrations:
    php artisan migrate
  3. Verify tables created:
    You should have: users, customers, tailor_orders, contact_inquiries
✓ Database Ready Your tailor orders and customers will be stored securely in SQLite database.

3 Build Assets

  1. Build CSS and JavaScript:
    npm run build
  2. Or run in development mode (auto-rebuilds):
    npm run dev

4 Start the Application

  1. Option A: Simple (one terminal):
    php artisan serve
    Then visit http://127.0.0.1:8000 in your browser.
  2. Option B: Full development (another terminal for assets):
    Terminal 1: php artisan serve
    Terminal 2: npm run dev
  3. Option C: Using Composer script (all at once):
    composer dev

5 First Time Setup

  1. Visit http://127.0.0.1:8000/setup
  2. Create your tailor account (name, email, strong password)
  3. You'll be logged in automatically
  4. Go to /workroom to see your dashboard
✓ Ready to Go! Your tailoring workroom is now live and ready for customers.

6 System Features

Customer-Facing:

  • Home / Booking Page: Customers fill beautiful fitting form with 3-step wizard
  • Order Tracking: Track by reference number + phone (privacy-protected)
  • Contact Form: Send messages directly to your workroom

Tailor/Admin Features:

  • Dashboard: Overview of active orders, customers, and messages
  • Order Management: Create orders, update status (new → delivered), track payments
  • Customer Profiles: Keep measurements, email, notes for each customer
  • Quick Order Entry: Add orders directly from workroom with existing/new customers
  • Price Tracking: Manage total cost and advance payments, auto-calculate balance
  • Inquiries: Manage contact messages and mark as handled

9 Deployment (Production)

When ready to go live:

  1. Set APP_ENV=production in .env
  2. Set APP_DEBUG=false
  3. Generate strong app key if changed
  4. Use a real hosting provider (Heroku, Digital Ocean, AWS, or local VPS)
  5. Switch to PostgreSQL or MySQL for better production reliability
  6. Set up proper backups of customer data
  7. Use HTTPS with SSL certificate
  8. Configure email sending for real notifications
